# JOAT feature audit, September 4, 2026

Status: audit complete at the source, synthetic-controller and simulator-fixture levels. Thirty-four bounded findings are recorded below. Product fixes and physical-G2 acceptance remain outstanding.

## Scope and evidence

The requested product is a conversational assistant that can use Brainstorm, Agent Terminal, Messages, QuickNotes, Overview, News, Timer, and Navigation. A complete journey includes opening, reading, speaking, reviewing an action when needed, seeing a truthful outcome, and returning or switching features.

Audited the primary checkout on `main`, HEAD `8386bf5f4a69239c7f7ee84a709cf47701ea242c`, Hub plugin `0.1.74`. The starting tree already contained changes to the orchestrator, gateway, Whisper adapters, tests, changelog, and recovery documentation. They were preserved. The audit is of that working tree, not a claim about the package currently installed on the phone. Only audit artifacts and a bounded changelog entry are authored here. No product implementation, real message transmission, package build/upload, installation, or production-service restart is part of the audit.

Evidence labels:

- **Source mechanism (L2):** the complete inspected call/state path can produce the stated failure. This does not prove it happened to the wearer.
- **Synthetic occurrence:** production code reproduced a failure with isolated test data. This proves the fixture outcome, not a real-device incident.
- **Simulator fixture:** current production rendering with synthetic state. This proves visible layout only; interactive paths are recorded separately.
- **Unverified:** current deployment, real permissions, external service behavior, physical optics, or latency requiring a wearer trace.

The user's report establishes the symptom but supplies no measured failure rate or latency percentile. The existing local `voice-latency.json` receipt was absent when checked. Historical reports and prior passing screenshots are not fresh acceptance.

## Confirmed and bounded gaps

Priority P1 means a core journey is blocked, materially misleading, or can lose user work. P2 means incomplete behavior, restricted coverage, or a misleading state with a narrower impact. Priorities are audit judgments, not measured incident frequencies.

### Assistant and speech

**A1, P1: conversational feature access is missing from the supported tool interface.** The complete registry contains location/weather, notifications, headlines, search, Pomodoro status, and optional recent-message summaries. No tools expose message compose/reply/send, note capture, feature opening, timer mutation, Brainstorm control, Terminal control, or route start. Deterministic handlers run first; unmatched text goes to the conversational seat; returned prose is displayed rather than redispatched into those handlers. Search can activate its panel, so the registry is not entirely read-only. [Registry](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:463), [MCP dispatch](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_endpoint.py:399), [feature command routing](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/commands.py:71), [response rendering](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:449).

**A2, P1: prompted Messages and Terminal speech can be discarded before reaching the prompt owner.** The UI asks for a reply, recipient, body, or Terminal instruction, but the pre-wake-word exception is only implemented for an explicitly armed Brainstorm topic. The ordinary gate rejects unaddressed follow-up speech. This does not mean ambient room speech should become a command; the missing contract is scoped speech admission after the wearer explicitly entered an input flow. [Reply prompt](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:205), [compose prompts](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:254), [Terminal prompt](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:1046), [admission order](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:395).

**A3, P1: no prompt interruption path ahead of the full voice-turn worker.** STT and the complete reply serialize in one worker. One completed pending utterance is retained; further utterances replace it. Spoken stop/correction therefore waits behind the operation it should interrupt, and a sequence of follow-ups can lose intermediate turns. [Queue and worker](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:291).

**A4, P2: the Codex seat's stream is buffered.** It collects subprocess output until completion, then parses and yields the response. Claude supports partial output. Both spawn a process per turn and have a 90-second reply ceiling; that ceiling is not an end-to-end voice deadline. [Codex collection](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/agents/cli_reply_engine.py:436), [Claude partial output](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/agents/cli_reply_engine.py:333).

**A5, P1/P2: batch STT lacks an inference deadline; visible transcription is final-only.** The batch adapter awaits the subprocess without a timeout, including the resident-adapter fallback. The normal pipeline waits for VAD endpointing and final transcription. Having G2 microphone PCM support does not supply a transcription or draft-review UI. [Batch wait](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/audio/whisperkit.py:93), [fallback wait](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/audio/whisper_serve.py:449), [VAD defaults](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/audio/vad.py:51).

**A6, P1 acceptance gap: current latency telemetry cannot establish speech-end to visible-answer latency.** Its clock begins after endpointing and queue wait, and its final event is a transport send rather than a lens paint. Deterministic-command outcomes omit the normal first-reply/completion events. The receipt was absent locally. Previous 80.17-second cold readiness and 5.05-second warm readiness measurements describe isolated Mac STT processes, not current glasses responsiveness. [Instrumentation](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:372), [receipt schema](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/voice_latency.py:1), [historical evidence](/Users/emmanuelakinwale/Developer/joatGlass/docs/WHISPER_COLD_START.md:15).

**A7, P2: internal work and ordinary conversation share a CLI context and lock.** Voice, the Even AI endpoint, Brainstorm judge/synthesis, and transformation operations receive the same seat switch. A CLI seat owns one resumable session and lock. This creates a source-confirmed route for internal prompts to enter conversation history and for unrelated operations to wait on each other. The extent of answer contamination is unmeasured. The visible judge label still says local although the selected seat can be cloud-backed. [Judge composition](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:844), [transformation composition](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:800), [seat state](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/agents/cli_reply_engine.py:146), [label](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1828).

**A8, P2: the Even AI endpoint ignores caller history and buffers streaming responses.** It extracts only the newest user turn, then collects the full answer before constructing SSE output. A resumable shared CLI context is not equivalent to honoring each caller's supplied conversation. [History extraction](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_endpoint.py:139), [response collection](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_endpoint.py:315).

### Messages

**M1, P1, synthetic occurrence: committed messages in live WAL can be invisible.** `IMessageStore._connect()` sets `immutable=1` even though Messages is actively updating its WAL. With a synthetic database and one committed WAL row, this production connection returned zero rows; ordinary `mode=ro` returned one. No user message database was read in this experiment. SQLite's immutability contract assumes no other process changes the file, and WAL commits can precede checkpointing into the main file. [Production open](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/channels/imessage.py:373), [SQLite URI semantics](https://www.sqlite.org/uri.html#uriimmutable), [SQLite WAL semantics](https://www.sqlite.org/wal.html). This is a separate reproduced mechanism, not another admitted link in the conversational Why chain.

**M2, P1: older/newer history navigation has a broken wire contract.** The Mac puts paging instructions in the heading and supplies a footer reading `tap read · say reply · left x2: back`. The plugin only enables history requests when the footer contains `down older` or `up newer`. Consequently a real Mac-authored conversation cannot request those pages through this gate. [Mac payload](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:927), [plugin gate](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/CapabilityMenu.ts:1192).

**M3, P1: Back restores a picker whose server-side row mapping was erased.** The plugin displays its cached conversation rows and emits `messages-list`. The Mac responds by clearing `_message_rows`; a subsequent conversation selection fails a bounds check and returns silently. [Cached restoration](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/CapabilityMenu.ts:1279), [mapping clear](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:454), [selection guard](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:738).

**M4, P1/P2: read-only groups cannot be opened for reading.** The group reply restriction returns before loading conversation history. It also produces an overlay instead of the list response expected by the plugin's pending selection state. Preventing an unverified group send does not require preventing group reading. [Early return](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:758), [pending selection](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/CapabilityMenu.ts:736).

**M5, P2 coverage: source and picker content are incomplete.** Only `message.text` is decoded; null/empty text is omitted unless an attachment flag supplies a generic placeholder. `attributedBody` is not decoded. The picker contains only five conversations selected from a bounded sixty-row incoming scan, with no conversation-list pager. Whether rich-text omission affects the wearer's actual database remains unverified. [Query and filtering](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/channels/imessage.py:194), [history query](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/channels/imessage.py:311), [picker limit](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:665).

**M6, P1: ordinary new-message intent cannot start composition.** The recognized form is `message [to] <recipient> saying/with <body>` and still requires that the wearer previously selected New message. The request “send a message to my wife” lacks an action tool and a supported contextual initiation path. Contact resolution matches names/word prefixes and does not resolve relationship labels. Exact names with multiple addresses can remain ambiguous. [Grammar](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:42), [compose prerequisite](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:309), [contact lookup](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/channels/contacts.py:67).

**M7, P1/P2: no visible editable transcription flow.** The orchestrator publishes the transcript only after awaiting the whole command, which includes confirmation/send. Feature pages buffer ordinary Context text until Back. Draft review is the final confirmation, not an editable speech transcript. Recipient plus body must fit 120 UTF-16 units; longer drafts are rejected for redictation. [Command ordering](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:449), [focus buffering](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/HudPresenter.ts:310), [draft limit](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:339).

**M8, P2: model message reads are snapshots even when the UI has more.** The assistant's tool exposes eighty characters per sender and no full-thread selection/reader operation. Separately, `reply to him/her/them` can be consumed by the broad reply regex as draft text before the intended bare-reply handler. The Messages.app sender also has an unbounded `osascript.communicate()` wait. [Tool truncation](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/agents/builtin_tools.py:214), [reply match order](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:156), [sender wait](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/channels/message_sender.py:54).

**M9, P1/P2: character pagination can overflow the visible reader.** The Mac paginates by characters, but the plugin wraps by words and displays at most ten body lines. A synthetic 307-character message made from eleven 27-character words fits one Mac page yet wraps into eleven lines. The last line has no following page. The probe executes production pagination/wrapping helpers with a manually assembled reader payload, not the actual draw routine; it supports the clipping mechanism rather than an observed optical loss. The News article reader shares the wrapping/display boundary and uses larger character pages. [Message pagination](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:957), [reader composition](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/HudCanvasRenderer.ts:1135), [visible line cap](/Users/emmanuelakinwale/Developer/joatGlass/apps/hub-plugin/src/HudCanvasRenderer.ts:2256), [article pages](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/panels.py:48).

**M10, P2: initial database absence becomes permanent for the capability router.** Startup injects `None` when the Messages store is unavailable. A later retry in the capability router has no store to probe, so creating or making the database available later cannot recover that router until the engine restarts. This is source evidence; the wearer's startup state was not examined. [Startup injection](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:1381), [capability availability guard](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:651).

Counterevidence: the one-to-one UI reader exists, uses retained text, and splits it into 320-character pages. That is a page size, not a total-message limit; M9 explains why this still does not guarantee complete visible reading. Short-message draft, confirmation, submission and uncertain-result handling also exist. It would be inaccurate to report them as wholly absent. [Reader](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:957), [send outcomes](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/message_reply.py:438).

### Brainstorm and Agent Terminal

**B1, P1: an active Brainstorm owns speech even after another feature is opened.** The session consumes addressed text before the normal command router. Arbitrary text becomes a `YOU` turn. Feature-opening, Terminal cancellation and model-switch phrases can therefore be swallowed while a Brainstorm remains active. Changing the visible page does not transfer speech ownership. [Active-session dispatch](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:435), [arbitrary utterance consumption](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1536), [upstream order](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/orchestrator.py:418).

**B2, P1: Brainstorm-to-Terminal handoff is not a real roster handoff.** It paints the Brainstorm's activity as a running Hermes terminal with empty lanes. Terminal input arming then requires no active session, so a tap can be ignored while the Brainstorm remains active. [Painted handoff](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/sinks.py:330), [input guard](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1008).

**B3, P2: browsing prior analysis and claiming verified synthesis have incomplete contracts.** Selecting a saved session starts continuation rather than a read-only transcript view. Completed live turns become gists. Citation parsing treats no citations as a pass without determining whether factual claims require citations, and the generated final synthesis lacks its own verification pass. This is a gap against the documented verified-synthesis promise, not proof that every answer is false. [Saved selection](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/capabilities.py:731), [continuation](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1196), [gist rendering](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/sinks.py:189), [citation gate](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1941), [synthesis](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:1804).

**T1, P1: a successful approval can receive a false conflict explanation.** The roster returns a human-readable sentence such as `work: recorded approve ...`. The gesture handler compares that whole sentence with bare `approve` and labels the mismatch as another controller answering first. Error/no-pending strings are similarly susceptible to being wrapped as recorded results. [Wiring](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:1088), [roster receipt](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_terminal.py:742), [consumer comparison](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/session.py:944).

**T2, P2: session discovery and reading remain incomplete.** Boot builds a fixed roster from one runtime configuration. Discovery uses the first eligible lane and replaces its target. Long output lines and resumed history are truncated before the renderer can wrap them. The roadmap itself retains multi-host/concurrent-session acceptance gaps. [Boot roster](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/__main__.py:1225), [discovery](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_terminal.py:587), [line truncation](/Users/emmanuelakinwale/Developer/joatGlass/apps/mac/joat/services/agent_terminal.py:320), [roadmap](/Users/emmanuelakinwale/Developer/joatGlass/docs/AGENT_TERMINAL_ROADMAP.md:120).

## Bounded causal conclusion

Accepted Why 1, L2: ordinary phrasing misses deterministic command handlers → the model receives a registry without the required feature operation → its output is rendered, so the supported conversational path cannot execute that operation. The controllable cause in this branch is the incomplete shared action interface between the conversation and existing feature controllers.

Three independent primary origins support the necessary integration mechanism: [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling), [Anthropic tool use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview), and [Google function calling](https://ai.google.dev/gemini-api/docs/function-calling). Each requires callable capability exposure, application execution and result feedback. An independent challenge admitted this as a source mechanism only. It is not a universal explanation for WAL reading, QuickNotes control mismatch, UI paging, or physical latency. Deeper process blame would be speculative.

**One intervention:** make the Mac's feature controllers available through one stateful action interface shared by the conversational seat and feature UI. The owning system is the Mac capability/session layer. It acts where intent becomes a controller operation and binds selected target, input ownership, action identity, review/confirmation and returned result to the same session. This removes A1's capability barrier and provides a single place to enforce complete feature journeys; the independent defects catalogued above still need their own acceptance evidence before any feature is called complete. This is a proposal, not an implemented fix.

**One seven-day indicator:** the proportion of a fixed set of twenty ordinary-language action requests that reach the correct feature controller with the correct target, required confirmation and returned result through the shared interface. Measure correlated dispatch/result receipts against safe fixture controllers. Baseline is unmeasured, not zero; establish it on day one and target twenty of twenty by day seven. This indicator tests the admitted conversational-access cause. Complete-feature acceptance separately still requires second visits, Back, long-content reading, prompted speech, switching during Brainstorm, confirmation refusal, and physical-G2 speech/latency evidence; this one intervention does not automatically correct their independent defects.
